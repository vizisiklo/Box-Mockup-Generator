# Release notes

## Free Beta 1.5.3 — Windows x64 (Experimental, frozen)

This is the **final public Free Beta binary**. Further development will happen privately for a separate full edition. Only public documentation and the [development changelog](CHANGELOG.md) may be updated here.

**Distribution:** Portable Windows executable, published separately via [GitHub Releases](https://github.com/vizisiklo/Box-Mockup-Generator/releases).

### Features
- Guided 5-step workflow: dimensions → PDF/SVG template → artwork → studio settings → PNG.
- Live 3D box preview and UV template panel.
- Rounded edges; portrait and landscape layouts.
- CorelDRAW-compatible vector atlas; exported template filenames contain dimensions.
- Material presets, lighting, shadows and camera positioning.
- Final 1440 × 1440 PNG mockup.
- 24 EU languages, with Windows-language detection and manual selector.
- Optional OBJ and batch-render functions.

### Limitations
- Free Beta: may contain rendering, UI and language issues.
- Templates represent UV atlases, **not** manufacturing dielines.
- Windows 10/11, 64-bit; no official macOS or Linux version.
- This repository does **not** publish the application's proprietary source code.
- Before downloading, verify that an executable asset has been attached to the [Releases](https://github.com/vizisiklo/Box-Mockup-Generator/releases) page.
